# StyleSync

StyleSync is an AI-powered wardrobe assistant that tells you what to wear. Upload
photos of your clothes and StyleSync builds them into a digital closet-
automatically removing backgrounds and tagging each item then recommends
complete outfits tailored to the occasion and day you pick. It's installable as a
PWA and runs entirely on a free-tier stack.

**Built with:** Next.js · Supabase (Postgres + pgvector, Auth, Storage) · a
Hugging Face Space (CLIP + rembg) for image processing · Gemini API for outfit
recommendations · deployed on Vercel behind Cloudflare.
